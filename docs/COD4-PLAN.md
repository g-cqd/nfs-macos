# Runtime refresh and Call of Duty 4 delivery

## Phase 1: preserve and pin

- Preserve the original game folders, saves, and delivered Most Wanted v5 apps.
- Pin the updated development branches of mtld3d and x87sidecar to tested binaries and matching source.
- Keep NFS 2015 diagnostics paused.

## Phase 2: native configuration and profiles

- Share the verified installer, transaction, process lease, and Rosetta setup between games.
- Add CoD4 settings from the installed engine's configuration and documented test output.
- Add profile creation, removal with backup, restore, import and export without embedding personal progress.
- Keep game changes in a private player folder; never write the original game or signed app.

## Phase 3: delivery

- Produce bundled and import editions for both games, with current runtime provenance and source notices.
- Validate configuration, profile recovery, imports, runtime dependencies, signing and notarization.
- Ask for targeted in-game checks where input is required; do not claim unmeasured frame rates.

The deployment floor remains macOS 15 and Swift 6. The native launcher is not an App Sandbox: Wine drive isolation does not prevent all host access. Maximum quality means native display resolution and the highest verified game settings; MetalFX spatial scaling remains available as a quality/performance choice.
